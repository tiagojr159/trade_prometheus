# Legacy and benchmark tools

Only the full historical engine and the v2 alignment utilities represent current directional semantics. `SIDEWAYS` remains a valid market regime and is not, by itself, evidence that a file is legacy.

| FILE | CLASSIFICATION | SEMANTICS | REPLACEMENT | SAFE TO RUN? | NOTES |
|---|---|---|---|---|---|
| `admin/probe_baselines.php` | `LEGACY_V1` | Reads mixed historical prediction results, including ternary `SIDEWAYS`; owns old correctness comparisons and uses unseeded random baseline. | `admin/alignment_baselines_v2.php` for current v2 baseline comparison; `evaluation/HistoricalPipelineBacktester.php` for full pipeline generation. | Historical/debug only; visible LEGACY warning is printed. | Preserved; do not cite output as current performance. |
| `admin/audit_probe_1.php` (baseline section) | `LEGACY_V1` | Historical `backtest_results` comparison; now scoped to `evaluation_version=1`. | `admin/alignment_baselines_v2.php` | Safe read-only diagnostic; visible LEGACY warning. | Other sections audit data sources and operations. |
| `evaluation/WalkForwardBacktester.php` | `UTILITY_NOT_AFFECTED` | Simplified technical-only comparison, with v2 direction and explicit `evaluation_version=2`; it does not run the full six-module pipeline. | `evaluation/HistoricalPipelineBacktester.php` | Safe for isolated comparison; writes v2-tagged rows when invoked. | Not a v1 tool; “simplified” is its limitation. |
| `admin/alignment_baselines_v2.php` | `CURRENT_V2` | Filters `evaluation_version=2`, delegates direction/hit/Brier/log loss to `DirectionPolicy`, uses a matched directional subset. | — official baseline comparison. | Safe to run read-only. | Different from a full pipeline backtest. |
| `admin/alignment_confusion_v2.php` | `CURRENT_V2` | Filters v2 results, uses `DirectionPolicy` for predicted direction/hit and reports confusion/calibration. | `admin/alignment_baselines_v2.php` for baseline comparison. | Safe to run read-only. | Report only; not a predictive validation claim. |
| `admin/probe_baselines_v2.php` | `CURRENT_V2` | Filters v2; uses `DirectionPolicy` for prediction, targets, hit, Brier and log loss. | `admin/alignment_baselines_v2.php` | Safe to run read-only. | Retained as an earlier v2 probe. |
| `admin/migrate_eval_v2.php` | `UTILITY_NOT_AFFECTED` | Administrative recomputation of `prediction_results` under v2; it is not a benchmark and does not alter `backtest_results`. | — | Writes results and a logical backup; do not run as part of this temporal hardening. | Its scope is the prediction results table, distinct from backtest rows. |
| `evaluation/HistoricalPipelineBacktester.php` | `CURRENT_V2` | Runs actual modules at point-in-time AsOf, applies v2 direction policy, stores version 2. | — official full-pipeline historical engine. | Writes to `backtest_results`; run only when intended. | Strict lineage rules exclude legacy inputs whose receipt time is unknown. |
| `evaluation/MetricsCalculator.php` | `UTILITY_NOT_AFFECTED` | Updates per-module aggregates only after `PredictionEvaluator` evaluates with v2 semantics. | — | Safe within evaluation pipeline. | It does not query or combine `backtest_results` versions. |

`core/DirectionPolicy.php` remains the authority for predicted direction, actual direction, hit, Brier and log loss. `evaluation/OutOfSampleEvaluator.php`, `api/performance.php` and current dashboard performance queries explicitly scope results to version 2. `MetricsCalculator` receives v2-only evaluated predictions through `PredictionEvaluator`; its `module_performance` table has no evaluation-version dimension. Alignment reports are read-only checks over saved predictions and are not proof that their original external inputs had complete temporal lineage; only a fresh `HistoricalPipelineBacktester` run with the new lineage rules can test that reconstruction, and its usable sample may be sparse.
